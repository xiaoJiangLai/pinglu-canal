# 平陆运河科普平台

平陆运河智能科普网站高保真单页原型。从西江水系到北部湾，以「通航节点 / 工程奇迹 / 沿线概况 / 战略价值 / AI 智能科普」五个板块，讲清一条 134.2 公里运河的工程与人文。

## 目录结构

```
pinglu-canal/
├── index.html        # 页面结构（HTML）
├── css/
│   └── style.css     # 全部样式（含响应式断点）
├── js/
│   ├── data.js       # 数据层：沿线县区数据 + AI 问答数据
│   └── main.js       # 交互层：地图联动、AI 问答、滚动动效、导航高亮
└── README.md
```

## 使用方式

直接双击 `index.html` 即可在浏览器中打开（纯静态，无需构建）。

若浏览器对本地 `file://` 打开存在限制，可用任意静态服务器，例如：

```bash
# Python
python -m http.server 8080
# 然后访问 http://localhost:8080
```

## 结构说明

| 文件 | 职责 |
| --- | --- |
| `index.html` | 页面骨架与文案，引入 `css/style.css` 和两个 JS |
| `css/style.css` | 从原内联 `<style>` 拆分，含全部视觉样式与响应式规则 |
| `js/data.js` | 从原内联 `<script>` 拆分出的数据部分（`regionData`、`regionOrder`、`answerMap`） |
| `js/main.js` | 交互逻辑：县区切换、地图高亮、AI 问答、滚动动画、导航滚动高亮 |

## 后续扩展建议

- 接入真实大模型时，把县区、工程节点和专题组件作为工具（tools）开放给 AI 调用；
- 数据层与交互层已分离，便于后续把 `data.js` 替换为后端 API；
- 行政区地图为科普交互示意，不用于工程测绘、航行导航或行政边界认定。
